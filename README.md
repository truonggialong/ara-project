# Ara Project

Ứng dụng quản lý tiến độ dự án bằng biểu đồ Gantt cho macOS 14 trở lên (Apple silicon và Intel).

Tải bản cài mới nhất ở mục Releases: mở tệp `.dmg`, kéo Ara Project vào thư mục Applications.
Từ bản 1.1.8, ứng dụng tự báo và tự cài bản mới (menu Ara Project ▸ Kiểm tra bản cập nhật…).

Kho này chỉ chứa bản cài và bản tin cập nhật.
